# ☕ Coffee Shop Management System

A web-based Coffee Shop Management System developed to manage products, categories, orders, and users.

> **Role:** Backend Developer (Team Project)

## 📌 Overview

This project was developed as a university team project.

My responsibility was developing the backend using Laravel, designing the database, building RESTful APIs, and integrating with the frontend application.

## 🚀 Technologies

### Backend

* PHP 8
* Laravel
* MySQL
* RESTful API

### Frontend

* React
* TypeScript
* Vite
* React Router DOM
* Sass

### Tools

* Git
* Postman
* VS Code

## ✨ Features

* User Authentication
* Product Management
* Category Management
* Order Management
* User Management
* RESTful API
* Database Management

## 🛠 My Responsibilities

* Designed MySQL database.
* Developed RESTful APIs using Laravel.
* Implemented CRUD operations.
* Built authentication and authorization.
* Tested APIs with Postman.
* Collaborated with frontend developers for API integration.

## ⚙ Installation

```bash
git clone https://github.com/tam2411/coffee-shop-api.git

cd Coffee-shop

composer install

cp .env.example .env

php artisan key:generate

php artisan migrate

php artisan serve
```
